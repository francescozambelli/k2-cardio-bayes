# Abstract

**Course**: Advanced Statistics for Physics Analysis  
**Authors**: Chiara Maccani (2027591), Francesco Zambelli (2029014), Pietro Miglioranza (2029265)

The task of this work consists in the analysis of a dataset containing information about cardiovascular disease [1]. It is composed of 70,000 records of patient data described by 11 features and a target indicating the presence or absence of the disease.

After preliminary data manipulation and anomaly correction, the main goal of the project is to build the best classification predictive model using **Bayesian Networks**. In order to find the most probable belief-network structure, the **K2 algorithm** [2] is implemented and evaluated. The classification results and predictive accuracy are compared against other standard classification models, including **Decision Trees** and **Random Forests**.
